# MediPet

MediPet es una aplicación de escritorio para la administración de clínicas veterinarias.  
Fue desarrollada en **Java 17**, con interfaz gráfica en **JavaFX** y vistas diseñadas con **SceneBuilder**.  
La aplicación se conecta a una base de datos **MySQL** utilizando XAMPP.

---

## Características:

- **Gestión de Pacientes:** Registrar, actualizar y eliminar mascotas y sus datos.
- **Citas:** Agendar, cancelar y marcar citas como completadas.
- **Cartilla de Vacunación:** Visualización del historial de vacunas por mascota.
- **Dashboard:** Gráficas (línea y pastel) y conteos automáticos que muestran el estado general de la clínica.
- **Gestión de Usuarios:** Inicio de sesión y actualización de perfil.

---

## Tecnologías utilizadas:

- Java 17  
- JavaFX  
- SceneBuilder  
- MySQL (mediante XAMPP)  
- JDBC
